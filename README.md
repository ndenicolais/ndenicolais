## 📌 About Me

I am a **Frontend & Mobile Developer** who builds cross-platform mobile apps with **Flutter & Dart**, native Android apps with **Kotlin**, and web apps with **React and Next.js**.

My journey started in blockchain with React and PWAs, moved to native Android with Kotlin and Jetpack Compose, and settled on Flutter. Along the way I worked on microservice-based enterprise platforms, shared component libraries and server-driven UIs, with backend experience in PHP and Laravel.

**4+** years of experience · **2** companies · **28+** open source projects

My main areas of expertise include:

- Frontend development with React, Next.js, Vite and Tailwind CSS
- Cross-platform mobile development with Flutter and Dart
- Native Android development with Kotlin and Jetpack Compose
- REST API integration, microservices and database management
- UX/UI design, application state management and code review

I enjoy designing interfaces with Figma and transforming visual concepts into functional, maintainable and user-focused products.

I'm currently **open to new opportunities** — feel free to reach out!
